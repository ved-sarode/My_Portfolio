# Vedant Sarode - Bioinformatics Portfolio

Personal portfolio website for Vedant Sarode, a Bioinformatics graduate specializing in computational structural biology and protein modeling. 

This website features a custom neomorphic and glassmorphism design system to showcase research experience, publications, and technical skills bridging biology with computation.

## Technologies Used
- Next.js (React Framework)
- Tailwind CSS v4
- Custom CSS Glassmorphism & Hover Animations

## Local Development

To run this project locally on your machine:

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
