# Vedant Sarode - Bioinformatics Portfolio

Personal portfolio website built to showcase research experience, publications, and technical skills as a Bioinformatics graduate specializing in computational structural biology and protein modeling. 

Features a custom neomorphic and glassmorphism design system to visually bridge biology with computation.

## Technologies Used
- Next.js (React Framework)
- Tailwind CSS v4
- Custom CSS Glassmorphism & Hover Animations
